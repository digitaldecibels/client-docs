# Starlight docs site

Generated by `/docs-site --starlight`. The markdown in the repository's `docs/`
directory is the source; `src/content/docs/` is build output and is rewritten
on every run.

Dependencies are deliberately not pinned in `package.json`. They are installed
by name so the version resolved is whatever is current, rather than whatever was
current when this plugin was written:

```bash
npm install astro @astrojs/starlight sharp
```

Then:

```bash
npm run dev       # local preview, usually http://localhost:4321
npm run build     # static site into dist/
npm run preview   # serve what build produced
```

`dist/` is a plain static site. It needs to be served from a web root, so it
cannot simply be opened from a folder the way the default `/docs-site` output
can. That difference is the reason the client handoff still builds as a single
self-contained file.
